# PCE-842 Patrol Craft Escort

A WWII ship simulator set in the world of P-51 Mustang FS. You crew USS PCE-842 on coastal patrol, March 1945: stand watch as Officer of the Deck, run the engine room, work the radar, sonar and radio, steer from the pilothouse, man the 3"/50, 20 mm and twin 40 mm guns, and drop depth charges from the fantail.

Single HTML file (three.js r128 inlined), runs offline in any modern browser. Open `PCE-842.html`.

- **Game mode** for fun, **Hardcore** for a true simulation (Pause menu > Mode).
- **Stations:** keys 1-6 (press again for the station's next view). W / S engines, A / D rudder from anywhere.
- **Guns (5):** the mouse aims, Space or click fires, X looks up from the sight. T turns the practice targets on and off.
- **Controls:** press H for the on-screen box, P for the menu.

Ship model built from the PCE-874 Booklet of General Plans; gun figures from NavWeaps and the Navy's range tables. See `PLAN_PCE-842.md` for the design plan and progress.

`PCE-842_smoke_test.py` is a development check (headless Chromium via Playwright), not needed to play.

Version 0.10 (pre-release).
