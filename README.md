# PCE-842 Patrol Craft Escort

**Crew a WWII patrol craft escort in a single offline HTML file.**
Take any station aboard USS PCE-842 on coastal patrol, March 1945: conn her from the open bridge, answer the bells in the engine room, work the radar, sonar and radio, steer from the pilothouse, lay and fire her guns, and drop depth charges from the fantail.

## What you can do
| | |
|---|---|
| **Six stations** | Keys 1-6 put you at a station in first person; press the key again for its next view. The crew runs every station you are not manning. |
| **1 OOD** | The open bridge: gyro repeater, and 7 x 50 binoculars (X). |
| **2 Engineering** | The forward engine room: the engine-order telegraph rings, the engineer answers, the gauges follow the engine. |
| **3 Communications** | One seat, three devices: a sweeping surface-search radar, the sonar (range recorder, bearing repeater, ping and echo with Doppler) and the radio printing the traffic. |
| **4 Quartermaster** | The pilothouse: the wheel turns with the helm, rudder-angle indicator, compass, telegraphs. |
| **5 Gunner** | Man the 3"/50 forward (telescope), the 20 mm amidships (cartwheel ring sight, standing in the shoulder rests) or the twin 40 mm aft (ring sight). Real ballistics, magazines, drum changes and loaders. Kill rates on the towed sleeves follow the US Navy's wartime rounds per aircraft destroyed (Hardcore; game mode is 24 times faster). |
| **6 Torpedoman** | The OOD runs an attack on the exercise submarine and gives his orders by phone: be at the right weapon, set and armed, on time. Ripple-fire the Hedgehog, fire the K-guns each side, roll charges off the stern racks, then read the debrief and the pattern plot. Hardcore: walk the deck between them. |
| **Practice** | T puts out target rafts (two inside 20 mm range), towed sleeves for the 40 mm and 20 mm, and a dived exercise submarine for the sonar, the Hedgehog and the depth charges. |

## Game mode or Hardcore
- **Game mode:** engines and rudder from any station, wave motion can be switched off, sight rings show where to aim, shell cam follows your shots, targets are marked.
- **Hardcore:** a true simulation. The engines answer only from the engine room and the pilothouse, the sea always moves her, full gun smoke, and you set the 3"/50's sight range yourself.

Pause menu (P) > Mode.

## Controls (keyboard and mouse)
| | |
|---|---|
| W / S | engines ahead / astern (the order stays where you leave it) |
| A / D | rudder |
| 1 - 6 | stations (again for the next view) |
| Mouse | at a gun: aims (hold ` for big moves); Space or left click fires; X looks up from the sight; R reloads |
| 6, J | torpedoman: next position, go to the ordered one; Page Up / Down depth, X arm / safe, R load the Hedgehog |
| T | practice targets on / off |
| C | chase camera / back to your station |
| H | the on-screen controls box |
| P | pause menu (settings, mode, controls) |

A game controller works too (see the Controls page in the pause menu).

## Built from the real ship
The model is built from the PCE-874 Booklet of General Plans and photographs of PCE-842, in her Measure 32 dazzle. Gun figures (muzzle velocity, rates of fire, magazines, mount limits and rates, maximum ranges) come from NavWeaps and the Navy's range tables. Set in the world of [P-51D Mustang Flight Sim](https://github.mrrat.org/P51-Mustang-FS/).
